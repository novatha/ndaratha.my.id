Tujuan Pembelajaran

  • Mahasiswa dapat menginstal Python dan IDE.

  • Mahasiswa memahami konsep variabel dan tipe data di Python.

  • Mahasiswa dapat menggunakan operator aritmatika, perbandingan, dan logika.

  • Mahasiswa mampu menggunakan perintah input dan output dasar.

  • Mahasiswa mampu mengaplikasikan dasar-dasar ini dalam studi kasus sederhana.

Instalasi Python dan IDE

Python Python adalah bahasa pemrograman yang mudah dipelajari dan populer.

  • Unduh dari https://www.python.org/downloads/

  • Pastikan mencentang "Add Python to PATH" saat instalasi.

Integrated Development Environment (IDE) IDE membantu dalam menulis, menjalankan, dan mendebug kode.

  • VS Code: Populer, ringan, banyak ekstensi. (Unduh: https://code.visualstudio.com/)

  • PyCharm: Khusus Python, fitur sangat lengkap.

  • IDLE: Bawaan saat instalasi Python, cocok untuk pemula.

Variabel dan Tipe Data Dasar Variabel digunakan untuk menyimpan data. Di Python, Anda tidak perlu mendeklarasikan tipe data secara eksplisit (dynamically typed).

  • Integer (int): Bilangan bulat (misal: 10, -5)

  • Float (float): Bilangan pecahan (misal: 3.14, -0.5)

  • String (str): Teks (misal: "Halo", ‘Perpustakaan’)

  • Boolean (bool): Nilai kebenaran (True atau False)

    jumlah_buku = 150 # int denda_per_hari = 500.50 # float nama_peminjam = “Budi” # str status_kembali = False # bool

Operator Aritmatika Digunakan untuk operasi matematika dasar.

Operator Deskripsi Contoh

+ Penjumlahan 5 + 2 = 7 - Pengurangan 5 - 2 = 3 * Perkalian 5 * 2 = 10 / Pembagian (float) 5 / 2 = 2.5 // Pembagian bulat 5 // 2 = 2 % Modulus (Sisa bagi) 5 % 2 = 1 ** Pangkat 5 ** 2 = 25

Operator Perbandingan dan Logika Operator Perbandingan: Mengembalikan True atau False.

  • Sama dengan: ==

  • Tidak sama dengan: !=

  • Lebih besar / lebih kecil: >, <, >=, <=

Operator Logika: Menggabungkan kondisi logika.

  • and: True jika KEDUA kondisi benar.

  • or: True jika SALAH SATU kondisi benar.

  • not: Membalikkan nilai logika.

Input dan Output Dasar Output: print()

print(“Selamat datang di Perpustakaan!”) print(“Denda Anda adalah Rp”, 5000)

Input: input()

input() selalu mengembalikan string

Section titled “input() selalu mengembalikan string”

nama = input(“Masukkan nama Anda: “)

Konversi tipe data (Casting)

Section titled “Konversi tipe data (Casting)”

hari_terlambat = int(input(“Berapa hari terlambat? “))

Contoh: Kalkulator Denda Keterlambatan

Program sederhana menghitung denda keterlambatan buku

Section titled “Program sederhana menghitung denda keterlambatan buku”

TARIF_DENDA_PER_HARI = 1000

print(“— Kalkulator Denda Perpustakaan —”) nama = input(“Nama peminjam: “) hari_terlambat = int(input(“Jumlah hari keterlambatan: “))

Proses

Section titled “Proses”

total_denda = TARIF_DENDA_PER_HARI * hari_terlambat

Output

Section titled “Output”

print(“\nDetail Denda:”) print(“Peminjam:”, nama) print(“Total Denda: Rp”, total_denda)

Kesimpulan

  • Variabel digunakan untuk menyimpan data tanpa perlu deklarasi tipe secara manual di Python.

  • Memahami tipe data (int, float, str, bool) sangat penting.

  • Operator memungkinkan kita melakukan manipulasi nilai.

  • Fungsi input() dan print() memfasilitasi interaksi dengan pengguna (CLI).
