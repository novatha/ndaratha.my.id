Praktikum Software Open-Source & Lab

Panduan teknis penguasaan ekosistem perangkat lunak bebas lisensi untuk riset teknik elektro: GNU Octave, LTspice XVII, KiCad 8.0, Zotero, dan LaTeX PGFPlots.

5 Software Inti Ekosistem Riset Elektro

Komputasi Numerik & Model Analitis

GNU Octave

Perangkat lunak bebas lisensi untuk komputasi matriks, optimasi, penyelesaian persamaan diferensial sistem elektro, dan kalkulasi baseline closed-form.

  • Kompatibilitas sintaks MATLAB/Octave
  • Vektorisasi komputasi sinyal
  • Solusi ODE & optimasi parameter
  • Ekspor data mentah .csv
Simulasi Rangkaian Analog & Daya

LTspice XVII

Simulator SPICE industri berkecepatan tinggi untuk transien (.tran), AC analysis (.ac), dan sweep parameter komponen non-ideal (ESR, DCR, Rds_on).

  • Model non-ideal kapasitor & induktor
  • Analisis rugi-rugi switching MOSFET
  • Perintah .step param & Monte Carlo
  • Ekspor file gelombang .raw/.csv
Perancangan PCB & Prototyping

KiCad 8.0 EDA

Suite EDA open-source terkemuka untuk perancangan skematik elektrik, routing PCB 2-layer dengan ground plane, dan validasi Design Rule Check (DRC).

  • Schematic Capture & Netlist
  • Kalkulasi lebar jejak IPC-2152
  • Pemeriksaan DRC & isolasi tegangan
  • Generasi file produksi Gerber & Drill
Manajemen Sitasi Ilmiah

Zotero & Better BibTeX

Pengelola referensi ilmiah open-source untuk mengekstrak metadata jurnal Scopus/IEEE dan mengotomasi kunci sitasi ke berkas references.bib LaTeX.

  • Ekstraksi otomatis metadata PDF
  • Integrasi Better BibTeX citation key
  • Sinkronisasi koleksi riset
  • Ekspor format standar IEEE
Visualisasi Grafik Vektor Saintifik

LaTeX PGFPlots / TikZ

Paket LaTeX untuk menggambar kurva komparasi data hasil eksperimen secara vektor dengan kualitas publikasi tertinggi standar IEEE Transactions.

  • Grafik vektor tanpa degradasi resolusi
  • Plotting langsung dari dataset CSV
  • Kurva komparasi 3-Domain (Teori/Sim/HW)
  • Format label font menyatu dengan dokumen

5 Modul Praktikum Laboratorium Terpadu

MODUL 1 GNU Octave & LTspice XVII

Praktikum 1: Simulasi Filter RLC & Respon Frekuensi

Tujuan: Memvalidasi fungsi alih analitis ordo-2 terhadap simulasi domain frekuensi AC Sweep dan domain waktu transien.

Luaran: Laporan Praktikum 1 & Kurva Bode Plot Komparasi
MODUL 2 LTspice XVII

Praktikum 2: Simulasi Konverter Daya & Efek Parasitik

Tujuan: Memasukkan nilai ESR kapasitor filter, DCR induktor, dan resistansi internal untuk mengukur penurunan efisiensi riil.

Luaran: Laporan Praktikum 2 & Tabel Analisis Efisiensi
MODUL 3 KiCad 8.0 EDA

Praktikum 3: Perancangan PCB Sensor & Validasi DRC

Tujuan: Merancang skematik modular, routing jejak PCB 2-layer dengan ground plane solid, dan memeriksa error DRC.

Luaran: Arsip File Gerber RS-274X & Skematik PDF
MODUL 4 Digital Storage Oscilloscope & Python Logger

Praktikum 4: Pengukuran DSO & Logging Data Sensor

Tujuan: Mengkalibrasi probe DSO 10X, mengukur noise ripple tegangan, dan mengambil N >= 30 sampel data pengujian riil.

Luaran: Dataset Mentah CSV Pengujian Laboratorium
MODUL 5 GNU Octave & LaTeX PGFPlots

Praktikum 5: Analisis Statistik Error & Grafik TikZ

Tujuan: Menghitung metrik deviasi RMSE, MAE, dan MAPE serta menghasilkan grafik vektor komparasi 3-kurva siap publikasi.

Luaran: Skrip PGFPlots/TikZ & Grafik Komparasi Publikasi
