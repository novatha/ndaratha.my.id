Capstone Mini-Project: Docker Containerization

Deployment Microservices Terisolasi Berbasis Kernel Primitive (Namespaces & cgroups)

Unduh Panduan Capstone Project (.pdf)

Tujuan Capstone Project

Mahasiswa secara berkelompok (2–3 orang) merancang dan mendepolysikan arsitektur microservices terisolasi menggunakan Dockerfile dan docker-compose.yml. Mahasiswa diuji untuk membuktikan isolasi Linux Kernel Namespaces (PID, NET, IPC, MNT) dan pembatasan sumber daya cgroups (CPU & Memory Limits).

Luaran Komponen Capstone

1. Custom Dockerfile & Compose

Penulisan Dockerfile multi-stage build yang efisien dan berkas docker-compose.yml yang mengintegrasikan Web App, Database (PostgreSQL/MySQL), dan Reverse Proxy (Nginx).

2. Isolasi Kernel & Resource Limit

Konfigurasi batasan penggunaan memori (mem_limit: 512m) dan kuota CPU (cpus: 0.5) via cgroups serta verifikasi isolasi network bridge.

3. Presentasi & Project Defense (Mg 15)

Demonstrasi live deployment, uji coba isolasi proses (docker exec / ps aux), dan tanya jawab dengan tim dosen pada Minggu ke-15.
