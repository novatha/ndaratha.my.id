TUGAS 1 • Minggu 3 5% Total Nilai

Custom Linux Command-Line Shell

Bahasa C (POSIX System Calls)

Membangun program shell Linux kustom berbasis C yang mampu mengurai argumen perintah, melakukan `fork()` proses anak, mengeksekusi biner via `execvp()`, dan menunggu proses selesai via `waitpid()`. Dilengkapi penanganan signal interrupt (Ctrl+C).

TUGAS 2 • Minggu 5 6% Total Nilai

POSIX Thread Synchronization (pthreads & Mutex)

Bahasa C (pthreads & Semaphores)

Mengimplementasikan solusi bebas Race Condition dan Deadlock untuk masalah Producer-Consumer (Bounded Buffer) & Dining Philosophers menggunakan `pthread_mutex_t`, `pthread_cond_t`, dan `sem_t` dengan validasi ThreadSanitizer.

Virtual Memory Page Replacement Simulator

Bahasa C / Python Simulator

Merancang simulator pergantian halaman memori fisik yang menerima deretan trace alamat halaman logika dan membandingkan rasio Page Fault antara algoritma FIFO, Least Recently Used (LRU), dan Optimal (OPT).
