Minggu 7 Address Translation

Main Memory Management

Contiguous Allocation, Paging, Multi-level Page Table

Secondary Storage & RAID

Minggu 13 I/O Flow Analysis

I/O Subsystems & DMA

Interrupt-driven I/O, Direct Memory Access (DMA), Buffering

Minggu 14 Security Audit Analysis

Protection & Kernel Security

Access Control, Buffer Overflow, OpenBSD pledge/unveil, eBPF

Virtualization & Containerization
