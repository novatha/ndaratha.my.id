Capaian Pembelajaran Mata Kuliah (CPMK)

CPMK-1

Mampu menjelaskan konsep fundamental dual-mode, interrupt, silsilah sistem operasi Unix/Linux, arsitektur kernel (Monolithic, Microkernel, Hybrid), dan struktur OS modern.

CPMK-2

Mampu menganalisis abstraksi proses, thread concurrency, sinkronisasi POSIX (mutex, semaphore), penanganan deadlock, serta mengimplementasikan system call C.

CPMK-3

Mampu merancang dan mengevaluasi algoritma penjadwalan CPU (FCFS, SJF, Round Robin, MLFQ) dan manajemen memori virtual (Paging 64-bit, TLB, Page Replacement).

CPMK-4

Mampu menganalisis arsitektur sistem berkas (VFS, Inode, Ext4, ZFS CoW), penjadwalan storage sekunder, subsistem I/O, serta model proteksi keamanan kernel.

CPMK-5

Mampu mengimplementasikan isolasi proses tingkat lanjut, Linux Namespaces, Cgroups, dan orkestrasi container Docker dalam tugas proyek capstone praktikum.
